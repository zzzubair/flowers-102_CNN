# Flowers 102 Classifier

A from-scratch PyTorch CNN for classifying the 102 categories in the [Oxford 102 Flower Dataset](https://www.robots.ox.ac.uk/~vgg/data/flowers/102/). The included state dictionary records a 60.12% test result from the original project; that result has not been reproduced in the current environment.

## Setup

Python 3.10+ is recommended. Create an isolated environment:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

The requirements contain only the packages used by the scripts. PyPI installs the standard PyTorch build; for a platform-specific CUDA build, use the command generated by the official [PyTorch installer](https://pytorch.org/get-started/locally/) and then install the remaining requirements.

## Evaluate the included model

```bash
python evaluate.py
```

The first run downloads the Oxford Flowers 102 test data into `data/`. The checkpoint is loaded in PyTorch's restricted `weights_only` mode.

## Train from scratch

```bash
python train.py
```

Training downloads all three dataset splits, automatically uses CUDA when available, and defaults to the original two 1,000-epoch phases. Use `--epochs-per-phase` for a shorter experiment. Newly trained weights are not saved automatically.

## Test

```bash
python -m unittest discover -s tests
```

The tests use synthetic tensors and do not claim real dataset accuracy.
